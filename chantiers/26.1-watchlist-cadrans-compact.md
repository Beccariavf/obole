## 1. Contexte

La vue cadrans (#26) est appréciée mais la carte mesure **209–210 px** de haut : le cadran
de carte (92 × 53) occupe toute une ligne, suivi de 3 métriques empilées. La tête de tier
mesure 86 px (cadran 116 × 67).

Un débat contradictoire entre trois sous-agents (compact-first, visuel, juge) a comparé
quatre pistes. Les 2 meilleures :

- **A — mini-cadran 44 + valeur hors SVG + grille 2 colonnes** : 118 px, garde le cadran,
  zéro nouveau calcul (retenue) ;
- **B — barre de marge inline 150 × 6 + 3 métriques** : 117,7 px, plus dense mais supprime
  le cadran par carte et rend le libellé « Cadrans » approximatif (documentée, non
  implémentée).

Décision utilisateur : **option A**.

## 2. Objectif

Réduire la carte à **≤ 130 px** et la tête de tier à **≤ 50 px** sans rien perdre : nom,
marge (visuelle + texte), position σ, Pot. 5A et sa source, prix juste et sa source,
sélecteur de tier, Voir, retrait.

## 3. Non-objectifs

- L'option B, le backend, l'API, le MCP, le schéma SQLite.
- La vue Tableau, le jeu de convictions, les sources `valo`/`droite`.
- La sémantique des tiers, les formules de marge/z/potentiel, la géométrie `dialArc`.

## 4. Exigences

- **Tête de tier** : cadran 58 px, valeur 15 px **hors SVG** (texte HTML), libellé 9,5 px,
  `h4` + compteur, `section aria-labelledby`.
- **Carte** : cadran 44 × 26 décoratif (`aria-hidden`) à gauche ; ticker + nom (ellipsis +
  `title`) ; valeur de marge 12 px + « marge » 9 px ; ✕ 24 px avec `aria-label` ; métriques
  en 2 colonnes (σ | Pot. 5A + source, Prix juste + source sur toute la largeur) ; pied
  avec select 24 px et **Voir** 24 px (seule action d'ouverture, le titre n'est plus un
  bouton).
- **A11y** : focus `:focus-visible`, cibles ≥ 24 px, 3 arrêts/carte, contrastes, piste
  vide portée par l'arc et la valeur, `prefers-reduced-motion`, nom long tronqué.
- **Responsive** : 3/2/1 inchangé ; à ≤ 520 px les métriques passent à 1 colonne ; 390 px
  sans débordement.
- **Aucun** changement de données, de backend, de source, de tableau ou de jeu.

## 5. Critères d'acceptation

- [ ] Carte ≤ 130 px à 1440 (mesuré 118) ; tête de tier ≤ 50 px (42,6).
- [ ] La carte montre toutes les informations et le select affiche le tier réel (AMUN Tier 2).
- [ ] « Voir » ouvre la fiche ; ✕ retire ; le style d'erreur et l'état vide restent.
- [ ] A11y : ✕ nommé, sections titrées, focus visible, 3 arrêts, cibles 24 px, contraste,
      reduced motion.
- [ ] E2E Chromium + WebKit, suites front/backend, capture avant/après ; aucun schéma.

## 6. Décision

| Décision | Pourquoi |
| --- | --- |
| A (mini-cadran 44) plutôt que B (barre) | garde l'identité cadrans ; 118 px ; aucune nouvelle formule ; le nombre reste lisible en HTML. |
| Valeur hors SVG | un `<text>` SVG de 13 px rend à ~5,8 px dans un cadran de 44 px. |
| Tête de tier 58 + valeur HTML | 86 → 42,6 px ; garde la moyenne lisible. |
| Titre en `span`, Voir seule action | supprime le doublon d'arrêt de tabulation. |
| CSS scopé `.wl-card`/`.wl-tier-head` | `.wl-dial`/`.wl-card-k` sont partagés avec le duel. |

## 8. Risques

- Nom long : ellipsis + `title` ; la tête reste 28 px.
- 280 px : A garde 2 colonnes, Prix juste pleine largeur ; ≤ 520 px → 1 colonne.
- Classes partagées avec le jeu : scoper les règles ; ne pas toucher `.cv-card`/`.cv-score`.
- Serveur : `index.html`/CSS en cache → redémarrer avant la capture.
- Le libellé `.wl-dial-text` du tier doit rester le premier de la colonne pour l'e2e.
